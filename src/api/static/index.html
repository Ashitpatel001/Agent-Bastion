The 5-Stage Zero-Trust Pipeline

How ABSs secures autonomous agent sessions at the proxy level

DOM Sanitization Lens

Uses high-speed regex engines and secondary guardrail LLMs to scrub prompt injection payloads and hidden CSS traps before they reach the main agent's context.

Action Sentinel

Intercepts actions like clicks, inputs, and form submissions. Blocks dangerous injection sequences (e.g. SQLi keywords) and phishing redirections.

Dynamic DLP Firewall

Performs deep-packet content checking on outbound requests to detect honeytoken exposures, API key patterns, and session identifiers.

Dual-LLM Guardrails

Integrates Gemini 1.5 Pro to conduct forensic audits on suspicious DOM states, keeping performance overheads under 10ms for trusted paths.

Forensic XAI Explanations

When an action is blocked, it automatically generates a Root Cause Analysis (RCA) explaining why the security engine stepped in, mapped to risk metrics.

Real-time SOC Dashboard

Observe live actions, DOM differences (Raw vs Sanitized), and configure security parameters instantly with immediate enforcement.
